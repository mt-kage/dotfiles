# dotfiles
dotfiles for mt-kage.

## Install

### macOS

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/mt-kage/dotfiles/main/scripts/install.sh)"
```

### WSL (Ubuntu)

```bash
# Prerequisites
sudo apt update && sudo apt install -y curl git

# Run installer
bash -c "$(curl -fsSL https://raw.githubusercontent.com/mt-kage/dotfiles/main/scripts/install.sh)"
```

## Update

```bash
dot-update
```
